『순례주택』 갈등 분류 활동

분류 기준을 정한 뒤, 먼저 비슷한 갈등끼리 묶고 나중에 공통점과 유형 이름을 붙여 봅시다.

1. 분류 기준 정하기

예: 누구 사이의 갈등인가? / 무엇 때문에 갈등이 생기는가? / 어떤 가치가 충돌하는가?

2. 비슷한 갈등끼리 묶기

아직 유형 이름을 붙이지 마세요. 카드의 공통점을 생각하며 A~D 묶음으로 자유롭게 옮겨 봅시다. 2~4개 묶음만 사용해도 되고, 애매한 카드는 카드 모음에 남겨 두어도 됩니다.

3. 각 묶음의 공통점 찾기

먼저 공통점을 적고, 그다음에 묶음의 이름을 붙이세요.

4. 우리 모둠의 분류 결과

이 결과를 바탕으로 활동지에 분류 기준 → 유형 이름 → 여기에 속하는 갈등 → 공통점을 정리하세요.
